# Getting Support #

The best support resources for any felddy repository are its README and
its Discussions tab. Please search existing discussions and issues
before opening a new one.

- 💬 Use **Discussions** for questions, help, and ideas that are not
  yet concrete bug reports or feature proposals.
- 🐛 Use **Issues** (via the provided forms) for reproducible bugs and
  well-formed feature proposals.
- 🔐 For security problems, follow the
  [security policy](SECURITY.md) — never open a public issue.
