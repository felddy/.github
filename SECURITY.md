# Felddy's Security Policy #

## Reporting security problems ##

**DO NOT CREATE AN ISSUE to report a security problem.**

Instead, do one of the following:

- Use GitHub's
  [private vulnerability reporting](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing-information-about-vulnerabilities/privately-reporting-a-security-vulnerability)
  ("Report a vulnerability" on the repository's Security tab), where
  enabled.
- Send an email to
  [security@geekpad.com](mailto:security@geekpad.com). Sensitive
  information can be encrypted using my GPG key:
  [https://keybase.io/felddy](https://keybase.io/felddy)

You will receive a response acknowledging the report, and updates as
the problem is investigated and fixed.
